Una zona, tutte le zone

Pensato per chi ha più casse Bluetooth in casa e vuole decidere ogni volta dove suona cosa, senza reimpostare l'audio di sistema.

🎚️

Patch bay virtuale

Trascina un cavo dalla playlist a un output per collegarli — una traccia può suonare su più casse insieme, in tempo reale.

🎵

Playlist stile QLab

Pre-wait, durata, post-wait, loop, riproduzione al contrario, rotazione automatica tra output — controllo fine su ogni traccia.

📶

Ping keepalive

Un tono impercettibile (regolabile, anche ultrasonico) tiene sveglie le casse Bluetooth così non vanno in stand-by tra una traccia e l'altra.

🔋

Stato dispositivi

Percentuale batteria e nickname personalizzati per ogni cassa Bluetooth, sempre visibili nella colonna Output.

↩️

Annulla/ripeti

Conferma per ogni azione distruttiva (rimuovi traccia, rimuovi output, scollega tutto) e cronologia annulla/ripeti sulla playlist.

💻

Multipiattaforma nativo

PipeWire su Linux, CoreAudio su macOS (Apple Silicon), WASAPI su Windows — nessun layer di compatibilità, ogni backend parla l'audio di sistema direttamente.

ℹ️ Istruzioni — come aprire BlueCue dopo il download
🐧 Linux — AppImage
  1. Se il browser chiede "Mantenere il file?" clicca Mantieni.
  2. Rendi eseguibile il file e avvialo:
    chmod +x bluecue-linux.AppImage && ./bluecue-linux.AppImage
🍎 macOS — DMG
  1. Se il browser chiede "Consentire il download?" o "Mantenere?" clicca Consenti / Mantieni.
  2. Apri il file .dmg scaricato.
  3. Trascina BlueCue nella cartella Applicazioni.
  4. Espelli il disco e apri il Terminale (Applicazioni → Utility → Terminale).
  5. Esegui questo comando:
    xattr -cr /Applications/BlueCue.app
  6. Ora puoi aprire BlueCue normalmente dal Launchpad o dalla cartella Applicazioni.
Perché è necessario? BlueCue non è ancora notarizzata da Apple (firma solo ad-hoc, nessun account Apple Developer). macOS blocca qualsiasi app scaricata da internet non notarizzata mostrando "BlueCue è danneggiata e non può essere aperta". Il comando xattr -cr rimuove il flag di quarantena aggiunto automaticamente dal browser.
🪟 Windows — Installer
  1. Se il browser mostra "Questo file potrebbe essere dannoso" clicca Mantieni comunque (o Keep anyway).
  2. Avvia il file .exe scaricato.
  3. Se appare Windows Defender SmartScreen con "Il PC è stato protetto":
    clicca "Ulteriori informazioni" → "Esegui comunque".
  4. Segui la procedura guidata — installa anche il runtime Visual C++ necessario, in automatico.
Perché appare SmartScreen? Questa prima versione Windows non è firmata con un certificato code-signing a pagamento, quindi SmartScreen avvisa per l'installer non firmato. Il codice sorgente è pubblico su github.com/teonactl/bluecue — puoi verificarlo o compilarlo tu stesso. In alternativa all'installer c'è anche uno zip portatile: estrai la cartella BlueCue e avvia bluecue.exe direttamente, senza installare nulla.
